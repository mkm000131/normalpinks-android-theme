# normal pink s — Android KakaoTalk theme

Android port of the supplied `normalpinks.ktheme` for personal use. The build workflow reconstructs the theme from the original iOS colors/assets and produces an installable debug APK artifact.

## Build
Pushes to `main` run **Build Normal Pink APK**. Download the `normalpinks-apk` artifact from the Actions run and install the APK on Android, then apply **normal pink s** in KakaoTalk > Settings > Themes.
